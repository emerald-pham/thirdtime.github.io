# Subagent model guidance

6.1 Luna, 6.1 Terra, and 6.1 Sol are acceptable subagent models for this
repository, in addition to any other models already permitted.

Use only an exact model identifier exposed by the current runtime. The verified
identifiers are `gpt-6.1-terra` for 6.1 Terra and `gpt-6.1-sol` for 6.1 Sol.
As of 2026-10-27, the runtime does not expose a 6.1 Luna identifier; its use is
permitted when the runtime exposes the correct identifier. Never guess that
identifier or silently substitute `gpt-6-luna` for 6.1 Luna.

This allowance preserves existing model defaults, effort levels, speed modes,
security and access settings, required checks and reviews, project holds,
resource ownership, and active agents.
